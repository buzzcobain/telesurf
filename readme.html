This is a custom-built, retro-styled web browser running on the modern Electron engine.

Features

  • Vibrant Retro Styling: Aggressive CSS injection converts any website into a high-contrast terminal UI.
  • Tabs: Use Ctrl+T or Cmd+T to open new tabs, and click the 'x' to close them.
  • Shortcuts:
    • Cmd/Ctrl + T - New Tab
    • Cmd/Ctrl + W - Close Tab
    • Cmd/Ctrl + N - New Window
    • Cmd/Ctrl + L - Focus Address Bar
    • Cmd/Ctrl + R - Refresh Page
  • DuckDuckGo Integration: Just type a search query in the address bar to instantly search the web.
  • Favourites: Save your favorite sites using the [+ FAV] button. Right-click to remove them.

Built With

Electron, Node.js, and raw retro aesthetics.
